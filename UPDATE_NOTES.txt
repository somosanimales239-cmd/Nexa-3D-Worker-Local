NEXA 3D WORKER LOCAL 1.9.2 - WINDOWS UTF-8 PAINT FIX

Confirmed failure from Worker 1.9.1:
UnicodeEncodeError: 'charmap' codec can't encode character '\u2192'
in scripts/hunyuan_paint_proven.py while printing:
Front -> Left -> Back -> Right

What this update changes:
- Forces PYTHONUTF8=1 for Hunyuan child processes.
- Forces PYTHONIOENCODING=utf-8 for Hunyuan child processes.
- Reconfigures Python stdout/stderr to UTF-8 with replacement fallback.
- Removes Unicode arrow characters from Paint runtime messages.
- Bumps Worker version to 1.9.2.

What this update DOES NOT change:
- Hunyuan3D-2mv Shape settings.
- Remove Background / Randomize Seed.
- 30 steps / CFG 5.0 / Octree 256 / Chunks 8000.
- Four-view Shape order.
- Hunyuan Paint Turbo model/subfolder.
- CPU offload.
- Original RGBA Front/Left/Back/Right Paint input.
- Website/public_html.
- CUDA, PyTorch, Hunyuan models, or local environment.

This is intentionally a narrow repair of the exact Windows encoding crash.
