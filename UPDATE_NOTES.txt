NEXA 3D WORKER LOCAL 1.9.0 — PERSISTENT HUNYUAN 8082

Replaces the per-job Python runner. Nexa now uses the same local Hunyuan Gradio/FastAPI process on 127.0.0.1:8082. Shape + Paint load once and are reused. The patch is automatic and backed up. Exact Shape preset remains 30 steps / CFG 5.0 / octree 256 / chunks 8000 / Remove Background ON / Randomize Seed ON. Paint uses original RGBA Front -> Left -> Back -> Right and Paint Turbo with CPU offload. Raw white_mesh.glb is preserved. If raw geometry is above 100,000 faces, only the Paint copy is reduced to 80,000 faces to avoid the Windows high-poly xatlas stall. A safe inpainting dedup guard is applied when its expected source marker exists. A 30-minute watchdog reports failure instead of hanging for an hour. No Hunyuan/CUDA/PyTorch/model reinstall. No Stable Fast 3D. No Blender Texture Engine projection/baking. No page update is required when Nexa 3D Studio 2.2.3 is already installed.
