# Nexa-3D-Worker-Local
El worker está preparado para dos motores:  Stable Fast 3D, que será el predeterminado. Su proyecto oficial convierte una sola imagen en un modelo 3D y guarda el resultado como GLB; su configuración predeterminada ronda los 6 GB de VRAM. Hunyuan3D, opcional, mediante su API local oficial /generate, que puede recibir una imagen y devolver un GLB.
