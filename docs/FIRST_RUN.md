# First Run Checklist

- [ ] Nexa 3D Studio Update 8 Web is installed.
- [ ] Worker API base copied from Nexa 3D Studio Settings.
- [ ] Worker token copied from Nexa 3D Studio Settings.
- [ ] Nexa connection test passes.
- [ ] Python detected.
- [ ] Git detected.
- [ ] NVIDIA GPU detected if GPU acceleration will be used.
- [ ] Stable Fast 3D or Hunyuan3D local API is ready.
- [ ] Local Image → 3D Test creates a valid GLB.
- [ ] Start Worker shows Online.
- [ ] A Nexa Image → 3D job moves Queued → Processing → Completed.
